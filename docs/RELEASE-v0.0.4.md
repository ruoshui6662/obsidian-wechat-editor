# v0.0.4 操作区重组

本版重组编辑操作区，减少重复入口并明确正文、图片与文章内容的作用范围。Obsidian插件与浏览器助手清单统一为0.0.4，连接协议不变，已加载的v0.0.3助手可继续使用。

## 使用变化

- 顶部仍为互斥的编辑／预览。
- 正文常用设置精简为字体、字号、行距、段后距、两侧留白；标题设置合并，高级选项折叠。
- 图片使用整篇图片／当前图片切换。点图后只改这张，切回整篇不丢选择；没有选图时当前图片不可用。
- 轻阴影合并为一个开关。组合装饰预设取消，旧参数保留；圆角、边框、背景、投影和尺寸精调放在更多图片设置中。
- 重置当前图、把当前图样式设为整篇、统一已有差异分别表达，保存中不能切换写入范围。
- 文章设置管理复制标题、本篇开头和结尾；方案管理只保存样式。旧方案内容转为每篇独立副本，修改一篇不影响其他文章。

## 保留

28px默认段落／图文间距、18px蓝色分段三级标题、透明背景、轻边缘阴影、正文实际边距与手工不对称图片留白、实时预览、原生点图、最小侧栏宽度、状态栏避让和已有连接凭据。

## 验证与升级

独立审查指出的范围切换和保存重试问题已增加失败回归并修复。399项测试（57个文件）、类型检查、构建与打包通过；三个ZIP的CRC、SHA256、UTF-8文件名、版本和程序文件一致性校验通过。本地升级验证中，笔记、data.json和插件启用列表哈希不变。自动化不代表实机像素验收或微信端保存重开验收。

本地安装只替换插件文件夹里的main.js、manifest.json、styles.css；不覆盖data.json、笔记或启用列表。重新加载插件后确认显示0.0.4。升级后首次正常保存配置会保留旧方案头尾的本篇副本；无需重新配对浏览器。
