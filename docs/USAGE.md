# v0.0.2 使用与排版规则

## 写作、排版、预览

正文在 Obsidian 原生笔记编辑器撰写。打开 Markdown 笔记，在命令面板执行「公众号图文排版」。插件顶部「编辑｜预览」是互斥的两个功能页：编辑页只有参数，预览页只显示文章，不把预览挤到参数下面。

预览页保持打开时，继续在原生笔记里写作，正文会自动更新；图片处理完成后补齐。预览提供375px手机阅读参考，面板变窄时缩放查看，不代表所有手机的真实宽度。深浅主题跟随 Obsidian，复制到微信使用文章本身的配色，不会把深色界面直接复制过去。

## 全文文字设置一次生效

「全文排版」的字体、字号、行距、字距、段距、缩进与两侧留白作用于本篇正文。修改某个参数时覆盖旧局部段落的同项设置，其他参数和图片样式保留；标题有自己的层级字号。

| 参数 | 默认／范围 |
| --- | --- |
| 正文字号 | 默认16px；常用下拉与10–50px手动输入 |
| 行距 | 默认1.8倍；1–3倍可调 |
| 正文两侧留白 | 默认16px；0–96px可调 |
| 段前／段后 | 默认0／24px；0–48px可调 |
| 图片上下留白 | 默认各24px |
| 三级标题 | 默认18px、蓝色分段装饰；字号与装饰可调整 |
| 标题前后距 | 默认28／12px |

选择常用值立即应用；选择“手动设置”在同一行输入其他数字。清空不会被误当成0，明确填写0才表示不留白。底部“已保存”后可复制；失败时先重试保存。

“自动协调”取相邻间距需求的较大值，不把正文段后24和图片段前24叠成48。普通正文段落、文字到图片、图片到文字默认留24px；同段折行或单次换行仍由行距决定，Markdown 空行才分成新段。标题按独立的前后距处理；可在「段落节奏」改为原有间距。

### 三级标题

写 `### 标题文字` 即可。默认18px与蓝色分段小竖条，正文字号改变不影响三级标题。长标题续行与文字起点对齐；可关闭装饰，纯图片标题不额外加竖条。

## 图片：默认全文，点图单独改

没有选图时，图片区显示“文章默认”；修改作为本篇默认，单图已明确设置的参数保留。

在原生笔记的**实时预览**模式下单击独立段落图片，图片区改为“仅这张”。同一附件出现多次也可按位置分别调整，无需选择“第几处”。纯源码模式没有图片节点，阅读模式不接管点图；行内表情保持行内，不套独立图片排版。

- “返回文章默认”：回到文章默认的编辑范围。
- “使用文章默认”：清除当前图片局部样式。
- “应用到全文… → 设为文章默认”：把当前样式设成默认，保留其他单图已明确参数。
- “应用到全文… → 统一所有图片…”：确认后清除局部图片差异，全文用当前样式；可在底栏一步撤销。

首次单图调整可能在 Markdown 中添加 Obsidian 块 ID，用来稳定识别该段；它不会作为文章文字输出。主题、默认和统一等操作的撤销只保留在当前插件运行期间。

## 图片对齐与阴影

对齐只有四项：**左对齐、居中对齐、右对齐、两端对齐**。日常选择两端对齐，再选无阴影或轻阴影即可。

两端对齐默认与正文边缘一致。左右留白表示相对当前内容区域的实际空白，例如两侧16px就是各留16px；两侧8px会比留白16px的正文更宽，这是数值的含义，不是相对文字向外延伸的量。要相齐，保持相同留白或从其他对齐切换回两端对齐恢复正文边线。

两端对齐自动按边距计算宽度，不重复显示宽度参数。其他三种对齐可选择原始尺寸、40%、65%、100%或自定义百分比。手动边距覆盖后，正文留白改变不会擅自改变该显式值。

无阴影／轻阴影只改阴影，保留图片位置、宽度、圆角和底色。特殊效果在「更多样式」内：

| 预设 | 外观 |
| --- | --- |
| 原图 | 清除圆角、边框、阴影和底色，保留尺寸与位置 |
| 圆角 | 8px圆角、无阴影、保留透明 |
| 阴影 | 4px圆角、轻柔投影、保留透明 |
| 卡片 | 8px圆角、白色底板、较明显投影 |

预设会替换装饰字段；需要保留微调时使用单项控制。“固定圆角、边框与底色”仅把这些像素装饰生成副本，不扩大图片画布。阴影始终直接附在图片边缘，轻阴影为0横移、1px下移、8px柔和度、10%明暗；只加阴影时上传原始图片。正文与图片之间24px空白保留在HTML段落中，不画进图片。GIF 保留原始动画；微信最终装饰需实测。源图片自带白边／透明边不会自动裁切，阴影外延也不等同于照片边缘。

## 主题与我的方案

内置日常简洁、极简留白、科技蓝、宋韵阅读、温暖手记。顶部选择主题，手动微调后显示“已调整”；菜单可恢复主题。

“另存为”保存当前文字、主题、全文图片默认和头尾内容，之后在“我的方案”复用。单张图片的局部设置不进入可复用方案。切换主题保留单图差异及显式全文图片默认；要全篇图片完全一致，使用“统一所有图片…”。

头尾内容支持 Markdown，可用于固定开场、图源说明或文末推荐；默认复制正文，是否包含文章标题可在“更多文字选项”设置。

## 网络图片与附件命名

点击复制时，HTTP(S)网络图片先下载到本地，再上传微信；也可执行「下载网络图片到本地」命令单独处理。微信文章中的外链可能拒绝直接引用，本地化可减少失效；源站拒绝下载时仍需手动保存后插入。

附件位置：`文章目录/附件/文章名/网络图片-批次/图N.png`，真实格式决定扩展名。N按文章图片出现顺序编号，包含已有本地图片和模板头图；文件名不会作为图注出现在正文。重复URL只下载一次，每个位置各保存编号文件；后续调整文章顺序不会自动重命名旧附件。

正文下载成功后替换成相应本地引用；模板头尾图只为本次文章准备，不修改其他文章共用模板。文章变化或操作取消时停止旧任务，已保存的附件可能保留，不继续写入剪贴板。

## 字体

字体提供系统默认、系统黑体、系统宋体、思源宋体。思源宋体使用 [SIL OFL 1.1](https://github.com/adobe-fonts/source-han-serif/blob/master/LICENSE.txt)，可免费商用；插件不捆绑字体文件。本机预览需自行安装，其他设备或微信端不支持时回退为可用字体，不能保证所有手机显示同一字体。

## 复制与发布

使用“复制图文”后等待成功，到公众号**正文**普通粘贴。保存草稿重开、手机预览后再发布；插件不会自动发布。普通外链可能转为文字，需要在后台处理；失败、账号切换或文章变化时本次复制会停止，避免把旧任务当成成功。
