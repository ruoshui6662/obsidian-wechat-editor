# v0.0.5 使用与排版规则

## 写作、排版、预览

正文在 Obsidian 原生笔记编辑器撰写。打开 Markdown 笔记，在命令面板执行「公众号图文排版」。插件顶部「编辑｜预览」是互斥的两个功能页：编辑页只有参数，预览页只显示文章，不把预览挤到参数下面。

预览页保持打开时，继续在原生笔记里写作，正文会自动更新；图片处理完成后补齐。预览提供375px手机阅读参考，面板变窄时缩放查看，不代表所有手机的真实宽度。深浅主题跟随 Obsidian，复制到微信使用文章本身的配色，不会把深色界面直接复制过去。

## 全文文字设置一次生效

「正文」常用区只放字体、字号、行距、段后距、两侧留白五项，设置作用于本篇整篇正文。修改某个参数时覆盖旧局部段落的同项设置，其他参数和图片样式保留。标题字号和前后距在「标题」中；字距、段前距、首行缩进、对齐、颜色和相邻间距规则在「更多正文设置」中。

| 参数 | 默认／范围 |
| --- | --- |
| 正文字号 | 默认16px；常用下拉与10–50px手动输入 |
| 行距 | 默认1.8倍；1–3倍可调 |
| 正文两侧留白 | 默认16px；0–96px可调 |
| 段前／段后 | 默认0／28px；0–48px可调 |
| 图片上下留白 | 默认各28px |
| 三级标题 | 默认18px、蓝色分段装饰；字号与装饰可调整 |
| 标题前后距 | 默认28／12px |

选择常用值立即应用；选择“手动设置”在同一行输入其他数字。清空不会被误当成0，明确填写0才表示不留白。底部“已保存”后可复制；失败时先重试保存。

“相邻间距 → 合并留白”取相邻需求的较大值，不把正文段后28和图片段前28叠成56。普通正文段落、文字到图片、图片到文字默认留28px；同段折行或单次换行仍由行距决定，Markdown 空行才分成新段。标题按独立的前后距处理；旧“原有间距”模式兼容为“叠加留白”，不会因界面升级而静默改变原参数。

### 三级标题

写 `### 标题文字` 即可。默认18px与蓝色分段小竖条，正文字号改变不影响三级标题。长标题续行与文字起点对齐；可关闭装饰，纯图片标题不额外加竖条。

## 图片：默认全文，点图单独改

图片区使用「整篇图片｜当前图片」切换。没有选图时当前图片不可用；在“整篇图片”修改作为本篇默认，单图已明确设置的参数保留。已单独调整的图片会显示数量，统一操作只在存在差异时出现。

在原生笔记的**实时预览**模式下单击独立段落图片，自动进入“当前图片”。同一附件出现多次也可按位置分别调整，无需选择“第几处”。切回整篇不会丢失选图，再点当前图片即可返回；切文章会清空选图。纯源码模式没有图片节点，阅读模式不接管点图；行内表情保持行内。

- “重置这张图片”：清除当前图片局部样式，恢复整篇设置。
- “用这张的样式设置整篇图片”：把当前样式设成默认，保留其他图片已单独调整的参数。
- 整篇范围下的“统一为整篇样式…”：确认后清除局部图片差异，所有图片用整篇样式；可在底栏一步撤销。

首次单图调整可能在 Markdown 中添加 Obsidian 块 ID，用来稳定识别该段；它不会作为文章文字输出。主题、默认和统一等操作的撤销只保留在当前插件运行期间。

## 图片对齐与阴影

对齐只有四项：**左对齐、居中对齐、右对齐、两端对齐**。日常选择两端对齐，再选无阴影或轻阴影即可。

两端对齐默认与正文边缘一致。「更多图片设置 → 使用正文留白」开启时随正文边距变化；手工填写左右留白会解除继承。左右值表示相对当前内容区域的实际空白，例如两侧16px就是各留16px，8px会比留白16px的正文更宽。切换对齐只改对齐，不再偷偷重置手工边距。

两端对齐自动按边距计算宽度，不重复显示宽度参数。其他三种对齐可选择原始尺寸、40%、65%、100%或自定义百分比。手动边距覆盖后，正文留白改变不会擅自改变该显式值。

“轻阴影”开关只改投影，保留位置、宽度、圆角、边框和背景。原有自定义投影读入后保留；关掉再打开使用轻阴影参数。圆角、投影精调、边框、透明／纯色背景、宽度与上下左右留白都收在「更多图片设置」。组合外观预设和图片处理开关已移除，旧样式数据保留。

圆角、边框和明确设置的底色由程序自动处理，不扩大画布。阴影沿图片边缘显示，轻阴影为0横移、1px下移、8px柔和度、10%明暗；只加阴影时上传原始图片。正文与图片之间28px空白保留在HTML段落中，不画进图片。GIF保留原始动画；微信最终装饰需实测。源图片自带白边／透明边不会自动裁切。

## 主题与我的方案

内置日常简洁、极简留白、科技蓝、宋韵阅读、温暖手记。顶部统一选择排版方案，手动微调后显示“已调整”；管理菜单可恢复方案样式。

“管理 → 保存为新方案…”只保存正文和整篇图片样式，在“我的方案”复用。单张图片的局部设置和本篇内容不进入新方案。切换内置风格保留单图差异及显式整篇图片默认；要所有图片完全一致，在整篇范围使用统一操作。

「文章设置」集中管理复制时包含标题、文章开头和文章结尾。开头／结尾支持Markdown和本地图片，只修改本篇。旧方案中的开头结尾会保留为各关联文章的独立副本；修改本篇不会影响其他文章。切换文章后尚未保存的内容弹窗会拒绝过期提交，需回到原文章重新打开。

## 网络图片与附件命名

点击复制时，HTTP(S)网络图片先下载到本地，再上传微信；也可执行「下载网络图片到本地」命令单独处理。微信文章中的外链可能拒绝直接引用，本地化可减少失效；源站拒绝下载时仍需手动保存后插入。

附件位置：`文章目录/附件/文章名/网络图片-批次/图N.png`，真实格式决定扩展名。N按文章图片出现顺序编号，包含已有本地图片和模板头图；文件名不会作为图注出现在正文。重复URL只下载一次，每个位置各保存编号文件；后续调整文章顺序不会自动重命名旧附件。

正文下载成功后替换成相应本地引用；模板头尾图只为本次文章准备，不修改其他文章共用模板。文章变化或操作取消时停止旧任务，已保存的附件可能保留，不继续写入剪贴板。

## 字体

字体提供系统默认、系统黑体、系统宋体、思源宋体。思源宋体使用 [SIL OFL 1.1](https://github.com/adobe-fonts/source-han-serif/blob/master/LICENSE.txt)，可免费商用；插件不捆绑字体文件。本机预览需自行安装，其他设备或微信端不支持时回退为可用字体，不能保证所有手机显示同一字体。

## 复制与发布

使用“复制图文”后等待成功，到公众号**正文**普通粘贴。保存草稿重开、手机预览后再发布；插件不会自动发布。普通外链可能转为文字，需要在后台处理；失败、账号切换或文章变化时本次复制会停止，避免把旧任务当成成功。

升级v0.0.3时，现有文章、局部图片和个人方案中沿用的旧24px默认间距会一次性升级为28px，其他自定义值保留。升级后仍可手动选择24px或其他数值，不会在下次启动时强制重置。同段行距与标题间距不变。
