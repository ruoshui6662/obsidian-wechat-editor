# v0.0.5 复制稳定性更新

本版针对复制中途停止、短暂断线需要从头重试和重复图片处理较慢的问题。**Obsidian 插件与浏览器图片助手都需要更新至0.0.5**；保留原连接记录和文章设置。

## 修复

- 暂时读不到微信账号时重查一次，并报告“无法核对”，不再误判为换号。真正换号仍停止旧任务。
- 只在当前正文或实际引用的图片变化时取消旧复制；不再被无关附件、无关笔记重命名和相同内容的保存打断。
- 同一助手的短暂本机断线可在15秒内恢复原任务。已完成上传通过结果确认回传；不重新发送上传POST。
- 取消和超时按任务传入微信页面，停止对应请求。页面85秒、助手95秒、本机120秒的上传预算留出结果回传时间；账号检查20秒。
- 首页GET请求在网络、HTTP或正文读取失败时最多重试一次；账号不符、微信业务拒绝、图片上传POST不自动重试。
- 重复图片的相同外观复用处理结果；上传时减少重复登录扫描，保留上传前后账号检查。

## 更新

Obsidian安装只替换main.js、manifest.json、styles.css，不覆盖data.json。浏览器助手更新文件后，在扩展管理页点击刷新；原来从本地dist/extension加载的助手也需刷新。重新加载Obsidian插件，确认两端版本0.0.5。

## 边界

15秒恢复针对同一仍在运行的助手，不承诺浏览器／Obsidian彻底重启后继续旧任务。超过恢复期限、真实换号、文章变化或授权被接管时应按提示重新复制。取消无法撤销微信服务器已接受的上传。

458项测试（61个文件）、类型检查、构建与打包通过；三个ZIP已通过CRC、SHA256、版本一致性与私密内容排除校验。主笔记库更新前后笔记、配置和启用列表哈希一致。独立代码审查无未解决的重要问题。

回归包含真实本机WebSocket的复制、断连恢复和结果确认；不等同于真实微信后台保存重开验收。
