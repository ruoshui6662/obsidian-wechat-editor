## v0.0.2 · 图片边缘轻阴影修复

修复旧版阴影合成时扩大图片画布、再靠负边距抵消的处理。新版阴影直接附在图片边缘，不增加白色外框；只加阴影时上传原图，圆角／边框副本也不扩大画布。

轻阴影为10%明暗、8px柔和度、1px下移。正文与图片之间的24px空白保留在正常HTML段落中，不合进图片。透明图片不默认填白，GIF保留动画。

**更新后请重新从Obsidian复制图文，替换微信草稿旧内容。已粘贴或上传的旧副本不会自动改变。**

下载wechat-layout-v0.0.2.zip安装Obsidian插件；浏览器助手同步提供wechat-layout-extension-v0.0.2.zip，本次通信协议未改变，已有连接无需重新配对。
