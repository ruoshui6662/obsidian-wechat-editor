## v0.0.3 · 默认图文间距28px

正文段落之间、正文到图片、图片到正文，默认统一为28px。自动协调只保留一处28px，不叠成56px。

已有文章、局部图片和个人方案中沿用的24px默认间距，在首次重载时一次性更新为28px；其他自定义值保留。升级后仍可手动调整，不会每次启动强制重置。同段行距与标题前后距保持，沿用v0.0.2的无外白边轻阴影。

更新Obsidian插件后请关闭再启用，确认版本0.0.3，再从Obsidian重新复制图文到微信。浏览器助手同步版本，无需重新配对。
