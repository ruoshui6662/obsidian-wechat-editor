## v0.0.1 首次公开发布

在Obsidian原生笔记里写作和调整图文，通过浏览器图片助手将配图上传到已登录的公众号，再把完整图文复制进后台。

### 下载

- **wechat-layout-v0.0.1.zip**：Obsidian插件。解压后把wechat-layout放入笔记库`.obsidian/plugins/`并启用。
- **wechat-layout-extension-v0.0.1.zip**：浏览器助手。Chrome／Edge扩展页开启开发者模式，加载解压后的extension文件夹。
- **test-vault-v0.0.1.zip**：独立示例库，可选。
- **main.js / manifest.json / styles.css**：Obsidian插件三文件，供手动更新或兼容安装工具使用。
- **SHA256SUMS.txt**：三个ZIP的完整性校验。

两个组件都安装后，助手点“连接Obsidian”，在Obsidian首次允许；同一浏览器登录公众号，核对账号名称后即可复制。无需AppSecret、长配对文本或手动复制Cookie。

[完整安装教程](https://github.com/ruoshui6662/obsidian-wechat-editor/blob/main/docs/INSTALL.md) · [浏览器配置](https://github.com/ruoshui6662/obsidian-wechat-editor/blob/main/docs/BROWSER.md) · [使用说明](https://github.com/ruoshui6662/obsidian-wechat-editor/blob/main/docs/USAGE.md) · [常见问题](https://github.com/ruoshui6662/obsidian-wechat-editor/blob/main/docs/TROUBLESHOOTING.md)
