# v0.0.3 安装与首次使用

需要安装 **Obsidian 插件 + 浏览器图片助手**。前者排版，后者上传图片；只装其中一个无法完成完整图文复制。支持同一电脑上的桌面 Obsidian 1.8.0+ 与 Chromium 116+ 浏览器。

## 1. 下载安装包

打开 [v0.0.3 发布页](https://github.com/ruoshui6662/obsidian-wechat-editor/releases/tag/v0.0.3)，在 Assets 下载：

- `wechat-layout-v0.0.3.zip`：Obsidian 插件。
- `wechat-layout-extension-v0.0.3.zip`：浏览器助手。
- 可选 `test-vault-v0.0.3.zip`：独立示例库，含插件与测试图片。

Release 尚在生成时，可从 [downloads 目录](https://github.com/ruoshui6662/obsidian-wechat-editor/tree/main/downloads) 打开 ZIP 后下载原始文件。不要将 GitHub 自动提供的 **Source code** 包当作安装包。普通用户无需安装 Node.js 或 pnpm。

## 2. 安装 Obsidian 插件

1. 打开你准备写作的笔记库，确认是这个库对应的本地文件夹。
2. 解压插件 ZIP，得到 `wechat-layout` 文件夹，内含 `main.js`、`manifest.json`、`styles.css` 和第三方许可文件。
3. 把整个 `wechat-layout` 放入笔记库的 `.obsidian/plugins/`；没有 `plugins` 就新建。
4. 打开 Obsidian「设置 → 第三方插件」，关闭限制模式以允许运行手动安装的插件；刷新已安装列表，启用「公众号图文排版」。首次允许插件是在你选择的这个笔记库中生效。
5. 按 `⌘P`（macOS）或 `Ctrl+P`（Windows／Linux）打开命令面板，搜索「公众号图文排版」，执行打开工作区。

正确目录如下，避免多套一层同名文件夹：

```text
你的笔记库/
└── .obsidian/
    └── plugins/
        └── wechat-layout/
            ├── main.js
            ├── manifest.json
            ├── styles.css
            └── THIRD_PARTY_LICENSES.txt
```

macOS Finder 使用 `⌘⇧.` 显示隐藏文件。Windows 文件资源管理器在「查看」中开启「隐藏的项目」。`.obsidian` 是**笔记库内**的配置目录，不是 Obsidian 应用程序安装目录。

每个笔记库独立安装和启用。安装到 A 库不会自动在 B 库出现。

### 可选：先体验示例库

解压 `test-vault-v0.0.3.zip`，在 Obsidian 的仓库管理中选择「打开本地仓库」，选 `test-vault` 文件夹。信任你下载的示例库并启用插件后，打开「日常测试」或「图片样式测试」。不要把整个测试库复制覆盖到自己的笔记库。

## 3. 安装浏览器图片助手

完整页面、权限和更新方式见[浏览器配置](BROWSER.md)。

1. 解压 `wechat-layout-extension-v0.0.3.zip`，得到 `extension` 文件夹。把它放到一个长期保留的位置；不要加载后再删除或移动。
2. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」（有些浏览器称“加载未打包的扩展程序”）。
4. 选择**直接包含 `manifest.json` 的 `extension` 文件夹**，不是 ZIP，也不是源代码根目录。
5. 确认扩展名为「公众号图文排版 · 图片助手」、版本为 `0.0.3`，启用扩展。可在浏览器扩展菜单中固定到工具栏。

Helium 等 Chromium 浏览器可从其扩展管理页加载，但应以实际兼容情况为准。Safari／Firefox 无法直接加载此包。

## 4. 首次连接

1. 保持 Obsidian 和已启用插件的笔记库打开。
2. 在安装助手的**同一浏览器和用户配置**里，打开 [mp.weixin.qq.com](https://mp.weixin.qq.com/) 并完成登录。保留一个有效后台标签页。
3. 从工具栏打开图片助手，点击「连接 Obsidian」。
4. 切回 Obsidian，在连接申请窗口点击「允许连接」。首次同意后，连接记录自动保存；无需复制配对文本。
5. 如果同时开着多个笔记库，助手会列出候选，选择你正在写作的那个库，再在该库允许。
6. 检查助手两块状态：**Obsidian 已连接**、**微信公众号 已就绪**，并核对公众号名称。两者都正常后才开始复制。

“已连接”仅指笔记库通信正常；“待登录”表示还需要处理微信登录。插件不会替你登录微信。

## 5. 第一次图文复制

1. 在 Obsidian 打开一篇包含独立段落图片的 Markdown 笔记。
2. 执行「公众号图文排版」命令。顶部「编辑」调整参数，「预览」查看文章。
3. 初次可选「日常简洁」主题，图片用“两端对齐”，再选无阴影或轻阴影。
4. 点击「复制图文」。程序会检查文章、下载网络图片、准备效果、上传图片，全部就绪后才写入剪贴板；按底部提示等待完成。
5. 打开公众号的图文编辑器，点击**正文编辑区域**，用 `⌘V` / `Ctrl+V` 普通粘贴。不要使用“粘贴为纯文本”。默认只复制正文，标题需要自己填写，或在插件中开启复制标题。
6. 检查图片数量、顺序、留白与字体，保存草稿后重开，并使用微信手机预览。最后由你手动发布。

复制过程中保持目标后台登录有效。失败时查看底部具体原因，再重试；不要把旧剪贴板内容误当成本次成功结果。

## 6. 日常使用与更新

浏览器与 Obsidian 重启后，打开原笔记库并登录微信，助手会自动尝试恢复。通常无需重新允许；后台过期时重新登录即可。不要反复卸载扩展，否则会丢失连接记录。

更新 Obsidian 插件：关闭插件，备份后只替换 `main.js`、`manifest.json`、`styles.css`（许可文件也可更新），**保留 `data.json`**，刷新列表再启用。浏览器助手更新：替换原 `extension` 文件夹内容，在扩展管理页点击该扩展的重新加载按钮，再刷新微信后台页。

首发为v0.0.1，当前间距版为v0.0.3；旧本地测试版即使版本号较高，也需要按上述步骤手动覆盖两个组件。Obsidian 与浏览器清单按规范显示 `0.0.3`，GitHub 标签和文档显示 `v0.0.3`，是同一版本。

若更新后仍显示旧版本，优先确认安装的是当前笔记库、扩展加载路径是新版文件夹，再刷新与重载。[问题排查](TROUBLESHOOTING.md)
